---
name: verify-work
description: Use before giving a final answer or delivering a file or code. Check the work instead of assuming it is right.
---
1. Re-read the request and tick off every requirement. Missing parts get fixed now, not mentioned later.
2. Numbers: recompute them with `calculate` or code. Do not trust mental arithmetic.
3. Files you created: open them again with `read_file` and confirm the content and the file name.
4. Code: run it if a shell is available, or at least read it once for syntax errors, wrong names and missing imports.
5. Facts: make sure each one comes from a source you actually read or from the user.
6. Report honestly. If something was not verified or could not be done, say exactly what and why.
